GHANTI GANG - Bell Bajao, Bhaago!
=================================

FRIENDS KE LIYE (sabse easy)
1. Zip ko unzip karo.
2. index.html par double-click karo (Chrome, Edge ya Safari mein khulega).
3. Story Mode, 20 levels, characters aur settings sab internet ke bina chalte hain.
   (Font ke liye internet ho to behtar, warna normal font dikhega.)
Phone par: file kholna mushkil hota hai, isliye link se khelna best hai (neeche Firebase steps dekho).

FIREBASE HOSTING PAR LINK BANANE KE STEPS (free)
1. Node.js install karo (nodejs.org).
2. Terminal mein: npm install -g firebase-tools
3. firebase login
4. console.firebase.google.com par naya project banao (free Spark plan chalega).
5. .firebaserc file mein YOUR-PROJECT-ID ki jagah apna project ID likho
   (ya is folder mein "firebase use --add" chalao).
6. Is folder mein: firebase deploy --only hosting
7. Terminal jo link dega (https://YOUR-PROJECT-ID.web.app) wo friends ko bhej do.
   Link phone aur computer dono par khulta hai.

DUSRE FREE OPTIONS
- Netlify Drop: app.netlify.com/drop par is poore folder ko drag-drop karo.
- GitHub Pages: files ek repository mein daalo aur Pages on karo.

NOTE
- Online multiplayer (Play Online with Friends) Claude ke andar chalne wale version mein hi kaam karta hai.
  Is downloaded version mein wo "not available" dikhayega. Story Mode poora chalta hai.
- Progress, stars aur settings har device ke browser mein alag save hote hain.
